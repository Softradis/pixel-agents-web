# Contributing to pixel-agents-web

Thanks for your interest in improving pixel-agents-web. Contributions are welcome, whether they are bug reports, feature ideas, discussions, documentation improvements, or code changes.

## Ways to contribute

- **Report bugs** with a clear reproduction path, expected behavior, actual behavior, screenshots or logs when useful, and your browser/runtime version.
- **Request features** by describing the problem, the proposed behavior, and why it would help users understand AI assistant work better.
- **Join discussions** for questions, design ideas, implementation tradeoffs, and broader conversations before opening a large pull request.
- **Improve documentation** when setup, deployment, event examples, or extension points are unclear.
- **Submit code** through pull requests.

## Before opening a pull request

1. Check existing issues and discussions to avoid duplicates.
2. Keep the change focused. Small, reviewable pull requests are easier to merge.
3. Run the project locally:

   ```bash
   npm install
   npm run build
   ```

4. Update documentation when behavior, setup, APIs, or deployment details change.
5. Make sure your contribution follows the [Code of Conduct](./CODE_OF_CONDUCT.md).

## Pull request checklist

- The change has a clear purpose.
- The app builds successfully with `npm run build`.
- Public-facing behavior is documented where relevant.
- New event types, layout changes, or integration assumptions are explained.
- The pull request description includes testing notes.

## Project direction

pixel-agents-web focuses on making AI assistant work visible in a simple pixel-art office: arrivals, assignment, handoffs, decisions, active work, and real completion events. Please keep contributions aligned with that goal.

## Support the project

If you find the project useful, consider supporting its development through the links in the README. Support helps keep the project maintained and improved.
