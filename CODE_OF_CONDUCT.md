# Code of Conduct

## Our pledge

We want pixel-agents-web to be a welcoming, respectful, and practical open-source project. Everyone participating in issues, discussions, pull requests, reviews, or community spaces is expected to help keep the environment constructive.

## Expected behavior

- Be respectful and considerate.
- Assume good intent, but accept corrections when impact differs from intent.
- Keep feedback specific, useful, and focused on the work.
- Welcome people with different backgrounds, experience levels, and perspectives.
- Disagree clearly without making it personal.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Sexualized language or imagery in project spaces.
- Personal attacks, trolling, or sustained disruption.
- Publishing private information without explicit permission.
- Any conduct that would reasonably make participation unsafe or hostile.

## Enforcement

Project maintainers may remove comments, close threads, reject contributions, or limit participation when behavior violates this Code of Conduct.

If you see or experience a problem, contact the maintainers through the repository maintainers or project owner. Reports will be handled with care and discretion.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, documentation, and community conversations related to pixel-agents-web.
